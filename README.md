# OcteDigital Engineering Operations

Welcome to the OcteDigital Engineering Operations repository.

OcteDigital is a digital growth agency that builds connected growth systems across 8 core arms: marketing, SEO, branding, web development, automation, content, analytics, and sales. This repository serves as the single source of truth for how our engineering organization supports that mission. It contains our shared community health files, issue and pull request templates, contribution standards, and overarching engineering guidelines.

## Purpose

As an organization-wide `.github` repository, the files contained here are automatically applied by GitHub as defaults for all repositories within the OcteDigital organization unless overridden locally.

Our goals are to:

- Standardize the way we work across all engineering teams.
- Maintain a high bar for code quality, security, and documentation.
- Provide a clear, welcoming onboarding experience for new engineers.
- Ensure consistent issue tracking and pull request reviews.

## Repository Structure

- `/profile/` - Contains our organization's public README.
- `/ISSUE_TEMPLATE/` - Standardized YAML templates for bug reports, feature requests, tasks, improvements, and documentation.
- `/docs/` - Comprehensive engineering handbook covering standards, architecture, organization, processes, and onboarding.
- `/CONTRIBUTING.md` - Guidelines for contributing to OcteDigital projects.
- `/CODE_OF_CONDUCT.md` - Our expectations for professional and collaborative behavior.
- `/SECURITY.md` - How to report security vulnerabilities responsibly.
- `/SUPPORT.md` - Where and how to get help.
- `/PULL_REQUEST_TEMPLATE.md` - The default template for all pull requests.
