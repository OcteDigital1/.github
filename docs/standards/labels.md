# GitHub Labels Standard

To maintain consistency in issue tracking and pull request management across all OcteDigital repositories, we use a standardized set of labels.

## Issue Types

- **`bug`**: Something isn't working as expected. Use when software violates requirements or crashes.
- **`enhancement`**: An improvement to existing functionality (e.g., refactoring, UI polish).
- **`feature`**: A completely new capability or product offering.
- **`documentation`**: Missing, incorrect, or requested documentation updates.
- **`security`**: Vulnerabilities or security-focused updates. Priority is automatically high.

## Domains

- **`backend`**: Changes affecting APIs, databases, or server-side logic.
- **`frontend`**: Changes affecting the UI, client-side logic, or styling.
- **`mobile`**: Changes related to iOS/Android applications.
- **`ai`**: Changes related to machine learning models, prompts, or data pipelines.
- **`devops`**: Changes affecting CI/CD pipelines, Docker, Kubernetes, or infrastructure.

## Status & Triage

- **`blocked`**: Development cannot proceed until an external dependency or decision is resolved.
- **`high priority`**: Must be addressed immediately (often reserved for critical bugs or hotfixes).
- **`good first issue`**: An isolated, well-defined task ideal for onboarding new engineers.
- **`help wanted`**: The maintainers are actively seeking community or cross-team help to resolve this.
