# Engineering Onboarding

Welcome to OcteDigital! We are thrilled to have you on the team. This guide provides a structured path to get you productive quickly.

## Day 1: Setup

1. **Access Management**: Ensure you have access to GitHub and any required internal systems.
2. **Local Environment**:
   - Install required tools (e.g., Git, Docker).
   - Configure Git with your OcteDigital email and setup SSH keys.
3. **Core Reading**:
   - [Engineering Philosophy](../engineering-philosophy.md)
   - [Branching Strategy](../standards/branching-strategy.md)
   - [Commit Convention](../standards/commit-convention.md)

## Week 1: First Contribution

1. Work with an engineering lead or repository maintainer to identify a task.
2. Branch off `develop` (e.g., `feature/my-first-task`).
3. Commit your changes using Conventional Commits.
4. Push and open a Pull Request against `develop`.
5. Experience our code review and integration process firsthand.

## Ongoing

- Familiarize yourself with our [Release Process](../processes/release-process.md).
- Review [Repository Ownership](../organization/repository-ownership.md) to understand team boundaries.
