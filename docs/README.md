## Core Reading

## Directory Structure

- [`architecture/`](architecture/) - Architectural Decision Records (ADRs) and high-level design documentation.
- [`organization/`](organization/) - Team structures and repository ownership.
- [`processes/`](processes/) - Operational procedures, release management, and [Communication Channels](processes/communication.md).
- [`standards/`](standards/) - Core guidelines covering branching, commit messages, code review, versioning, and [Issue Labels](standards/labels.md).
- [`onboarding/`](onboarding/) - Guides designed to get new engineers up and running quickly.
