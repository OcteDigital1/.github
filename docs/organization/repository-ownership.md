# Repository Ownership

Every repository at OcteDigital must have a clear, documented owner.

## The `CODEOWNERS` File

Ownership is strictly enforced via the `.github/CODEOWNERS` file in each repository. This ensures that Pull Requests automatically request reviews from the correct team.

## Responsibilities of a Code Owner

- **Triage Issues**: Review, label, and prioritize incoming bug reports and feature requests.
- **Review Pull Requests**: Uphold the [Repository Standards](../standards/repository-standards.md) and [Code Review Guidelines](../standards/code-review.md).
- **Security**: Promptly address vulnerability alerts (e.g., Dependabot) affecting the repository.
- **Releases**: Manage the lifecycle and deployment of the repository following our [Release Process](../processes/release-process.md).
