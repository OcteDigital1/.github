# Support Guidelines

If you need help with an OcteDigital project, please follow these steps to find an answer or get assistance.

## 1. Read the Documentation

Before asking for help, please review:

- The `README.md` of the specific repository.
- Search existing [Issues](https://github.com/OcteDigital1) (both open and closed) to see if your question has been answered.

## 2. Internal Engineering Channels

For OcteDigital employees:

- Reach out through designated internal engineering communication channels.

## 3. Opening an Issue

If you have found a bug or have a feature request, please use the appropriate Issue Template provided in the repository. Make sure to fill out all the requested information to help us assist you effectively.
